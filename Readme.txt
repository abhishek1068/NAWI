## 📌 Overview

**NAWI SmartLab** is a web-based digital platform designed to streamline the evaluation and test-report generation process for **Non-Automatic Weighing Instruments (NAWI)** in accordance with **OIML Recommendation R76**.

Traditional NAWI type-evaluation workflows often rely on manually maintained spreadsheets, documents, calculations, and report templates. This can result in repetitive work, calculation errors, inconsistent documentation, and difficulty maintaining complete test traceability.

NAWI SmartLab transforms this workflow into a structured digital process:

```text
Instrument Registration
        ↓
Instrument Profile
        ↓
Smart Test Applicability
        ↓
Personalized Test Plan
        ↓
Guided Test Execution
        ↓
Observation Capture
        ↓
Automatic Calculations
        ↓
Compliance Evaluation
        ↓
Technical Review
        ↓
PDF / DOCX Test Report
        ↓
Traceable Test History
